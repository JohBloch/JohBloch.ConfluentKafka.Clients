# JohBloch.ConfluentKafka.Clients

A .NET client library for Confluent Kafka.

## Getting Started

### Prerequisites

- .NET 8.0 SDK or later

### Building

```bash
dotnet build
```

### Running Tests

```bash
dotnet test
```

## Project Structure

```
├── src/
│   └── JohBloch.ConfluentKafka.Clients/     # Main library
├── tests/
│   └── JohBloch.ConfluentKafka.Clients.Tests/  # Unit tests
└── JohBloch.ConfluentKafka.Clients.sln      # Solution file
```
